# Legacy site (v1)

The original hand-written HTML portfolio, kept for reference. **Not built and not
deployed** — the live site is the Astro build at the repository root.

Preserved here because it holds the Phase 1 fixes (working mobile navigation,
honest contact form, privacy cleanup) applied before the rebuild, and the
original design notes.

- `index.html`, `about.html`, `projects.html`, `contact.html` — the four pages
- `main.js`, `styles.css` — shared behaviour and styles
- `design.md`, `interaction.md`, `outline.md` — original design notes
- `hero-cybersecurity.png` — stock hero image (not reused in v2)

To view it, open any of the HTML files directly in a browser or serve the folder
with a static server.
