# Portfolio Design Style Guide

## Design Philosophy

### Color Palette
- **Primary**: Deep Navy (#0A1628) - Professional, trustworthy, security-focused
- **Secondary**: Electric Blue (#00D4FF) - Tech-forward, dynamic, cybersecurity
- **Accent**: Cyber Green (#39FF14) - Hacker aesthetic, success indicators
- **Neutral**: Charcoal Gray (#2D3748) - Modern, sophisticated background

### Typography
- **Display Font**: "Canela" - Bold serif for headings, creates strong visual impact
- **Body Font**: "Neue Haas Grotesk" - Clean sans-serif for readability and modern feel
- **Code Font**: "JetBrains Mono" - For technical content and code snippets

### Visual Language
- **Aesthetic**: Cyberpunk meets professional security analyst
- **Mood**: Confident, competent, cutting-edge technology
- **Style**: High-tech interfaces, glowing elements, data visualizations
- **Inspiration**: Sci-fi UI design, cybersecurity dashboards, ethical hacking culture

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: Smooth animations for threat level indicator and skill radar
- **ECharts.js**: Interactive data visualizations for skills and project metrics
- **p5.js**: Creative coding for background particle effects and network visualizations
- **Pixi.js**: High-performance graphics for animated security interfaces
- **Typed.js**: Typewriter effect for hero section text
- **Splide.js**: Smooth project showcase carousel
- **Splitting.js**: Text animation effects for section headers

### Animation & Effects
- **Background**: Animated particle network with flowing data streams
- **Hero Text**: Typewriter animation with gradient color cycling
- **Skills Radar**: Interactive radar chart with hover animations
- **Threat Indicator**: Real-time gauge with smooth transitions
- **Project Cards**: 3D tilt effects on hover with depth shadows
- **Navigation**: Smooth scroll with active section highlighting

### Header Effect
- **Background**: Animated network topology with glowing nodes
- **Overlay**: Subtle gradient mask for text readability
- **Particles**: Floating data packets moving across the screen
- **Color Cycling**: Blue to teal gradient animation

### Interactive Elements
- **Buttons**: Glowing borders with hover expansion
- **Cards**: Lift effect with shadow depth on hover
- **Charts**: Smooth data transitions with tooltip animations
- **Forms**: Real-time validation with security-themed feedback

### Responsive Design
- **Mobile**: Stacked layout with touch-friendly interactions
- **Tablet**: Adaptive grid with optimized spacing
- **Desktop**: Full-width hero with side-by-side content sections

### Accessibility
- **Contrast**: 4.5:1 minimum ratio for all text
- **Focus States**: Clear keyboard navigation indicators
- **Alt Text**: Descriptive labels for all images and icons
- **Screen Reader**: Semantic HTML structure with proper ARIA labels
